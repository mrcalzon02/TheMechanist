The Mechanist: generated-world rendering baseline

October 25, 2026 · 3 world seeds · 5 slices · 15 positions · 34 before + 34 after frames · 1280 × 800 · entirely offscreen.

The source checkout does not build as-is. These are isolated diagnostic builds with temporary vehicle compile repairs and pure semantic-lookup caches. The actual source changes are visibility culling, camera-facing synchronization, removal of the blue vision guide, and focused regression coverage. See the exact limits below.

What exists and what changed

Existing modeDoom Mode is already implemented in GameOptions, OptionsScreenPainter, DoomRuntimeOptionsSubsystem and FirstPersonRenderViewport. Default off, FOV 80, persisted bounds 60-110, linear/radial fog. No replacement mode was created.
Existing game worldsWorldAtlas owns seeded, lazy slices across 3 x 3 sectors, 3 x 3 zones, ten main floors and sewer layers. The default insertion is the neutral civilian floor at sector 1,1 / zone 2,2 / floor 4. Tested seeds: 466713, 20261025, 8675309.
Existing rendering and artSwing/Java2D paints authored semantic tile, floor, wall, portrait, fixture and interface artwork. Doom is a software column raycaster over the same World; LWJGL availability does not make this path an OpenGL renderer.
Fixed: map visibility guideRemoved drawFacingVisionConeOverlay and its visual-only helper from LegacyPanelContext. Actual sensory visibility, illumination, exploration, movement previews, targeting and player indicators remain in place.
Fixed: distant spritesNPCs and map objects are rejected by GamePanel.isVisible before any portrait or semantic artwork lookup. Existing directional range, lighting and line-of-sight therefore gate sprites. Camera yaw now updates sensory facing while looking, without changing player coordinates.
Observed: generation stallsGenerate World calls generateScaffold synchronously on the Swing event thread. An unaccelerated offscreen sample also showed full registry scans during tile descriptor compilation. The user-reported failure was not established as a JVM crash.
Observed: render stallsThe original sprite pass processed over six thousand objects per slice and repeatedly searched semantic metadata. Matched captures show the distant horizon line disappearing after culling. Diagnostic cached Doom paint times still exceed a playable frame budget.
Pending: shared projectionStatic inspection finds wall rays use +X as forward at yaw zero while billboard projection uses +Z; horizontal projection also differs in aspect scaling. This pass does not redesign projection, target geometry or effects.
Pending: multi-level depthCurrent walls are one horizontal ray hit per screen column with a shifted horizon. Floor/ceiling are fixed planes; sprites lack shared per-pixel depth. Existing docs/DOOM_MULTILEVEL_RENDERING_PLAN.md describes the separate future multi-level work. Tile visibility culling does not provide partial sprite depth clipping.

Evidence limits

  • The unmodified checkout fails to compile: unresolved merge markers and duplicate local declarations in VehicleStrategicTransitCommitAuthority.java, plus a duplicate destinationKey in Milestone06FactionVehicleRouteTransitCommitSmoke.java.
  • All captures use current game sources compiled for Java 17 in an isolated diagnostic directory. The two vehicle files were repaired only in diagnostic copies, never in src/.
  • Diagnostic copies of SemanticRenderAssetResolver and SemanticAssetHintResolver memoize immutable semantic lookup results. No renderer or asset-selection rule was changed by these caches. Timings are diagnostic observations, not untouched baseline or release performance.
  • The existing fat jar supplied dependency classes and bundled assets on the classpath. Freshly compiled game classes take precedence. These are offscreen GamePanel.paint captures, not desktop screenshots or native GPU tests.
  • All tested slices use the smallest supported 500 x 500 setup; other setup values remain standard. Spawn is the real startPoint. Street and room points are developer relocations to existing walkable, unoccupied tiles, not alternate player-start features.
  • No packaged client/server jar, launcher, installer, or user save was replaced. Test storage is isolated. No desktop automation continued after the user requested exclusive desktop use.
  • The semantic texture-variant cohort regression fails with both the original and diagnostic resolver: a lower-priority generic floor is admitted. This was not repaired in this pass.
